# Changelog

## v0.2.0

- Added quick, standard, and deep audit modes with low-overhead quick mode as the default skill path
- Added baseline and local drift tracking, lightweight version-gap detection, and automatic escalation from quick to standard when the gap is large
- Added more compact markdown summaries with detailed expansion only for the most relevant skills
- Updated the published skill metadata, wrapper defaults, and English/Chinese READMEs around low-overhead governance
- Added tests covering quick-mode behavior and version-gap-triggered escalation

## v0.1.2

- Repositioned the project around the published Skill Guardian skill instead of the repository alone
- Reworked the English and Chinese READMEs to lead with skill installation, user outcomes, and audit decisions
- Updated skill display metadata for stronger public-facing branding
- Strengthened the markdown audit summary with clearer action-oriented conclusions

## v0.1.1

- Added `license: MIT` to the published skill metadata
- Added a minimal GitHub Actions CI workflow
- Improved README installation and publishing guidance
- Published release tag `v0.1.1`

## v0.1.0

- Initial public release of the `skill-guardian` repository and published skill
